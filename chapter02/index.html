하드웨어와 소프트웨어 — 몸과 마음¶

🎯 이 장에서 배우는 것¶

  • 하드웨어와 소프트웨어의 개념을 구분하여 설명할 수 있다
  • 컴퓨터의 기본 구성 요소를 입력-처리-출력-저장으로 분류할 수 있다
  • 시스템 소프트웨어와 응용 소프트웨어의 차이를 예시로 설명할 수 있다

📚 핵심 개념¶

개념 1: 하드웨어와 소프트웨어¶

하드웨어와 소프트웨어는 마치 사람의 몸과 마음과 같아요

사람이 생각하고 행동하기 위해서는 몸과 마음이 모두 필요하듯이, 컴퓨터도 하드웨어(몸)와 소프트웨어(마음)가 함께 작동해야 합니다.

하드웨어(Hardware): 컴퓨터의 물리적인 부품들 - 손으로 만질 수 있는 모든 것 - CPU, 메모리, 키보드, 모니터, 마우스 등

소프트웨어(Software): 컴퓨터에서 실행되는 프로그램들 - 눈에 보이지 않지만 기능을 수행하는 것 - Windows, 크롬 브라우저, 한글 프로그램 등

개념 2: 컴퓨터의 4가지 기본 기능¶

graph LR A[입력<br/>Input] --> B[처리<br/>Processing] B --> C[출력<br/>Output] B --> D[저장<br/>Storage]

입력 장치: 정보를 컴퓨터에 넣어주는 장치 - 키보드, 마우스, 마이크, 카메라

처리 장치: 입력받은 정보를 계산하고 처리하는 장치 - CPU(중앙처리장치), RAM(메모리)

출력 장치: 처리된 결과를 사용자에게 보여주는 장치 - 모니터, 스피커, 프린터

저장 장치: 정보를 보관하는 장치 - SSD, HDD, USB 메모리

🔨 따라하기¶

Step 1: 작업 관리자로 소프트웨어 확인하기¶

우리 컴퓨터에서 현재 실행 중인 소프트웨어들을 확인해보겠습니다.

실행 방법: 1. Ctrl + Shift + Esc 키를 동시에 눌러 작업 관리자를 엽니다 2. '프로세스' 탭을 클릭합니다 3. 현재 실행 중인 프로그램들을 확인합니다

확인할 수 있는 것: - 시스템 소프트웨어: Windows 관련 프로세스들 - 응용 소프트웨어: 크롬, 한글, 계산기 등

Step 2: 소프트웨어 분류하기¶

소프트웨어는 크게 두 가지로 나뉩니다:

graph TD A[소프트웨어] --> B[시스템 소프트웨어] A --> C[응용 소프트웨어] B --> D[운영체제<br/>Windows, macOS] B --> E[장치 드라이버<br/>프린터, 그래픽카드] C --> F[생산성 도구<br/>한글, PowerPoint] C --> G[인터넷<br/>크롬, Edge] C --> H[게임<br/>마인크래프트, 롤]

시스템 소프트웨어: 컴퓨터 자체를 관리하는 소프트웨어 - 운영체제(Windows 10, macOS) - 하드웨어를 제어하는 드라이버

응용 소프트웨어: 특정 작업을 위한 소프트웨어 - 문서 작성: 한글, MS Word - 인터넷: 크롬, Edge - 게임: 마인크래프트, 리그 오브 레전드

Step 3: 실습 - 내 컴퓨터 구성 요소 찾기¶

다음 하드웨어들을 실제로 찾아보세요:

노트북에서 찾기: - 🖱️ 입력: 키보드, 터치패드, 마이크 - 🧠 처리: CPU(보이지 않음), RAM(보이지 않음) - 📺 출력: 화면, 스피커 - 💾 저장: SSD/HDD(보이지 않음)

알아보기: CPU와 RAM은 노트북 내부에 있어서 직접 볼 수 없지만, '내 PC 속성'에서 확인할 수 있습니다!

⚠️ 주의할 점¶

하드웨어와 소프트웨어는 서로 의존적입니다 - 하드웨어만 있으면: 아무 기능도 하지 못하는 고철 덩어리 - 소프트웨어만 있으면: 실행할 수 있는 환경이 없음 - 둘 다 있어야: 비로소 컴퓨터로서 기능

성능의 균형이 중요합니다 - 최신 게임(소프트웨어)을 구형 컴퓨터(하드웨어)에서 실행하면 느려집니다 - 하드웨어와 소프트웨어의 성능이 균형을 이루어야 합니다

✅ 점검하기¶

  1. 키보드, CPU, 모니터, 한글 프로그램 중에서 소프트웨어는?
정답 확인 한글 프로그램입니다. 나머지는 모두 손으로 만질 수 있는 하드웨어입니다.
  1. Windows 운영체제는 시스템 소프트웨어일까요, 응용 소프트웨어일까요?
정답 확인 시스템 소프트웨어입니다. 컴퓨터 전체를 관리하고 다른 프로그램들이 실행될 수 있는 환경을 제공합니다.
  1. 스마트폰의 구성 요소를 입력-처리-출력-저장으로 분류해보세요
정답 확인 - 입력: 터치스크린, 마이크, 카메라 - 처리: CPU, RAM - 출력: 화면, 스피커 - 저장: 내장 메모리, SD카드
