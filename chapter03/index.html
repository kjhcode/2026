Chapter 03. 컴퓨팅 시스템의 구성 요소 한눈에 보기¶

🎯 이 장에서 배우는 것¶

  • 컴퓨팅 시스템을 하드웨어·소프트웨어·네트워크 3요소로 구조화할 수 있다
  • 각 구성 요소 간의 상호작용을 실제 환경 예시로 설명할 수 있다
  • 컴퓨팅 시스템의 전체 구조를 도식으로 표현할 수 있다

📚 핵심 개념¶

개념: 컴퓨팅 시스템의 3요소¶

컴퓨팅 시스템은 마치 오케스트라와 같아요. 각기 다른 악기들(하드웨어)이 있고, 악보(소프트웨어)가 있으며, 연주자들 간의 소통(네트워크)이 있어야 아름다운 음악이 완성되죠.

컴퓨팅 시스템이란 하드웨어, 소프트웨어, 네트워크가 유기적으로 결합되어 사용자의 요구를 처리하는 전체 환경을 말합니다.

graph TB A[컴퓨팅 시스템] --> B[하드웨어<br/>Hardware] A --> C[소프트웨어<br/>Software] A --> D[네트워크<br/>Network] B --> B1[CPU, 메모리, 저장장치] C --> C1[운영체제, 응용프로그램] D --> D1[인터넷, 통신 프로토콜] style A fill:#e1f5fe style B fill:#f3e5f5 style C fill:#e8f5e8 style D fill:#fff3e0

예시로 확인: 스마트폰으로 유튜브를 본다면? - 하드웨어: 스마트폰의 칩셋, 화면, 스피커 - 소프트웨어: 안드로이드 OS, 유튜브 앱 - 네트워크: 와이파이나 4G/5G 통신

🔨 따라하기¶

Step 1: AI 교실 환경 분석하기¶

우리 교실의 컴퓨팅 환경을 3요소로 분해해봅시다.

🔍 알아보기: 교실을 둘러보며 각 요소를 찾아보세요.

하드웨어 요소들: - 데스크톱/노트북 컴퓨터 - 스마트보드 또는 프로젝터 - 태블릿, 스마트폰 - 라우터(공유기)

소프트웨어 요소들: - Windows/macOS/Linux (운영체제) - 웹 브라우저 (Chrome, Safari 등) - 학습 관리 시스템(LMS) - 코딩 도구 (Python IDLE, 비주얼 스튜디오 코드 등)

네트워크 요소들: - 교내 무선 인터넷(Wi-Fi) - 인터넷 연결 - 클라우드 서비스 연결

Step 2: 상호작용 파악하기¶

각 요소들이 어떻게 협력하는지 살펴봅시다.

sequenceDiagram participant U as 사용자 participant S as 소프트웨어 participant H as 하드웨어 participant N as 네트워크 U->>S: 웹사이트 접속 요청 S->>H: CPU에 처리 명령 S->>N: 인터넷으로 데이터 요청 N->>S: 웹페이지 데이터 전송 S->>H: 화면에 출력 명령 H->>U: 웹페이지 화면 표시

📝 전체 구조도¶

graph LR subgraph "컴퓨팅 시스템" subgraph "하드웨어" H1[CPU] H2[메모리] H3[저장장치] H4[입출력장치] end subgraph "소프트웨어" S1[운영체제] S2[시스템 소프트웨어] S3[응용 소프트웨어] end subgraph "네트워크" N1[로컬 네트워크] N2[인터넷] N3[클라우드 서비스] end end H1 -.-> S1 S1 -.-> N1 S3 -.-> N2

⚠️ 주의할 점¶

  1. 상호 의존성: 세 요소 중 하나라도 문제가 생기면 전체 시스템이 제대로 작동하지 않습니다.

  2. 성능 균형: 가장 느린 구성 요소가 전체 시스템의 성능을 결정합니다. 예를 들어 인터넷이 느리면 아무리 좋은 컴퓨터를 써도 온라인 작업이 답답하죠.

💭 생각해보기¶

질문: 코로나19로 온라인 수업을 할 때, 어떤 컴퓨팅 시스템 요소들이 중요했을까요?

생각해본 답 확인하기 - **하드웨어**: 웹캠, 마이크, 안정적인 컴퓨터 - **소프트웨어**: 화상회의 프로그램(줌, 구글미트 등) - **네트워크**: 끊기지 않는 인터넷 연결 모든 요소가 골고루 중요했지만, 특히 **네트워크**가 가장 핵심적이었습니다!

✅ 점검하기¶

  1. 컴퓨팅 시스템의 3요소를 모두 말해보세요.
정답 확인 하드웨어(Hardware), 소프트웨어(Software), 네트워크(Network)
  1. 게임을 할 때 각 요소의 역할은 무엇인가요?
정답 확인 - 하드웨어: 그래픽카드로 화면 출력, CPU로 게임 연산 처리 - 소프트웨어: 게임 프로그램, 운영체제 - 네트워크: 온라인 게임의 경우 다른 플레이어와 연결
  1. 스마트홈을 컴퓨팅 시스템 관점에서 분석해보세요.
정답 확인 - 하드웨어: IoT 센서들, 스마트 기기들(에어컨, 조명 등) - 소프트웨어: 홈 자동화 앱, 기기 제어 프로그램 - 네트워크: Wi-Fi, 블루투스 등으로 기기들 간 통신
