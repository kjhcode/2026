    Chapter 05. 네트워크 구성 요소 탐험 — AI실 장비 찾기¶

    🎯 이 장에서 배우는 것¶

    • 라우터, 스위치, AP, 랜 케이블 등 네트워크 장비의 역할을 설명할 수 있다
    • AI실에서 실제 네트워크 장비를 찾아 사진과 함께 기록할 수 있다
    • 네트워크 토폴로지(스타형)를 그림으로 표현할 수 있다

    📚 핵심 개념¶

    개념: 네트워크 장비의 역할¶

    비유로 시작: 네트워크 장비들은 마치 우체국 시스템과 같아요! 편지가 목적지까지 전달되려면 우체국, 분류대, 배송 트럭이 필요하듯이, 데이터가 전달되려면 라우터, 스위치, 케이블이 필요합니다.

    정확한 정의: - 라우터(Router): 서로 다른 네트워크를 연결하고 데이터 경로를 찾아주는 장비 (중앙 우체국) - 스위치(Switch): 같은 네트워크 내에서 여러 기기를 연결하고 데이터를 전달하는 장비 (분류대) - 무선 접속점(AP): 유선 네트워크를 무선으로 확장해주는 장비 (무선 안테나) - 랜 케이블: 네트워크 장비와 컴퓨터를 물리적으로 연결하는 선 (도로)

    graph TB A[인터넷] --> B[라우터<br/>중앙 우체국] B --> C[스위치<br/>분류대] C --> D[컴퓨터 1] C --> E[컴퓨터 2] C --> F[AP<br/>무선 안테나] F -.무선.-> G[태블릿] F -.무선.-> H[스마트폰]

    예시로 확인: AI실에서 여러분이 인터넷을 사용할 때, 여러분의 컴퓨터 → 스위치 → 라우터 → 인터넷 순서로 데이터가 이동합니다.

    🔨 따라하기¶

    Step 1: 네트워크 장비 탐정 되기¶

    준비물: 스마트폰(카메라), 워크시트, 필기구

    실습 내용: 1. 천장 탐색: AI실 천장을 보며 AP(무선 접속점) 찾기 2. 벽면 탐색: 벽에 있는 랜 포트와 네트워크 패널 찾기
    3. 교탁 주변 탐색: 스위치나 라우터 찾기

    Step 2: 장비 위치 기록하기¶

    각 장비를 발견하면: 1. 스마트폰으로 사진 촬영 2. 워크시트에 위치 표시 (예: "천장 앞쪽 중앙", "뒷벽 오른쪽") 3. 장비 이름과 특징 기록

    Step 3: AI실 네트워크 지도 그리기¶

    발견한 장비들을 연결하여 AI실의 네트워크 구조 그려보기:

    graph TD A[인터넷] --> B[교탁의 라우터] B --> C[스위치] C --> D[컴퓨터 1번] C --> E[컴퓨터 2번] C --> F[컴퓨터 3번] C --> G[천장 AP] G -.무선.-> H[태블릿들] style C fill:#e1f5fe style G fill:#f3e5f5

    ⚠️ 주의할 점¶

    안전 주의사항: - 천장이나 높은 곳의 장비는 의자에 올라가지 말고 눈으로만 확인하세요 - 전기 장비에는 손을 대지 말고 관찰만 하세요

    관찰 팁: - AP는 보통 천장 중앙에, 작은 사각형 모양으로 설치됩니다 - 스위치는 여러 개의 랜 포트가 있는 직사각형 박스 모양입니다

    📝 네트워크 토폴로지 이해하기¶

    AI실의 네트워크는 스타형(Star) 토폴로지를 사용합니다:

    graph TB A[중앙 스위치] --> B[컴퓨터 1] A --> C[컴퓨터 2] A --> D[컴퓨터 3] A --> E[컴퓨터 4] A --> F[무선 AP] style A fill:#ffcdd2

    스타형의 장점: - 한 컴퓨터가 고장나도 다른 컴퓨터에 영향 없음 - 관리가 쉬움 - 속도가 빠름

    ✅ 점검하기¶

    1. 라우터와 스위치의 차이점은 무엇인가요?
    정답 확인 라우터는 서로 다른 네트워크를 연결하고 인터넷으로 가는 경로를 찾아주고, 스위치는 같은 네트워크 내에서 여러 컴퓨터를 연결해줍니다.
    1. AI실에서 발견한 네트워크 장비 3가지를 말해보세요.
    정답 확인 일반적으로 스위치(교탁 근처), 무선 AP(천장), 랜 포트(벽면)를 발견할 수 있습니다.
    1. 스타형 토폴로지의 장점 2가지는?
    정답 확인 1) 한 컴퓨터 고장이 다른 컴퓨터에 영향을 주지 않음 2) 중앙에서 관리하기 쉬움
