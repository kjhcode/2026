    8장. 프로토콜과 데이터 전송 — 약속이 있어야 대화가 된다¶

    🎯 이 장에서 배우는 것¶

    • 프로토콜이 왜 필요한지 일상의 예시로 설명할 수 있다
    • TCP/IP 계층 구조의 기본 역할을 이해할 수 있다
    • 데이터가 패킷으로 나뉘어 전송되는 과정을 설명할 수 있다

    📚 핵심 개념¶

    개념 1: 프로토콜(Protocol)¶

    프로토콜은 마치 사람들이 대화할 때 사용하는 '공통 언어'와 같아요.

    두 친구가 만났을 때를 생각해보세요. 한 명은 한국어만 알고, 다른 한 명은 영어만 안다면 대화가 될까요? 불가능하죠! 컴퓨터들도 마찬가지입니다.

    정확한 정의: 프로토콜은 컴퓨터들이 네트워크상에서 데이터를 주고받기 위한 통신 규칙입니다.

    예시로 확인: - 우리가 편지를 보낼 때도 약속이 있어요: 받는 사람 주소를 봉투 앞면에, 보내는 사람 주소를 뒷면에 쓰죠 - 전화를 걸 때도 "여보세요"로 시작하는 것처럼요

    개념 2: TCP/IP 4계층¶

    TCP/IP는 마치 택배 배송 시스템과 같아요.

    graph TD A[응용 계층<br/>Application Layer] --> B[전송 계층<br/>Transport Layer] B --> C[인터넷 계층<br/>Internet Layer] C --> D[네트워크 접근 계층<br/>Network Access Layer] A1[웹브라우저, 이메일] --> A B1[TCP, UDP] --> B C1[IP 주소] --> C D1[이더넷, WiFi] --> D

    각 계층의 역할: - 응용 계층: 우리가 사용하는 프로그램 (웹브라우저, 카카오톡) - 전송 계층: 데이터를 안전하게 전달 (TCP가 대표적) - 인터넷 계층: 목적지 찾기 (IP 주소 사용) - 네트워크 접근 계층: 실제 물리적 전송 (케이블, WiFi)

    개념 3: 패킷(Packet)¶

    패킷은 마치 큰 소포를 여러 개의 작은 상자로 나누는 것과 같아요.

    큰 파일을 한 번에 보내면 네트워크가 막힐 수 있어요. 그래서 작은 조각(패킷)으로 나누어 보내고, 받는 쪽에서 다시 조립합니다.

    graph LR A[큰 데이터] --> B[패킷1] A --> C[패킷2] A --> D[패킷3] A --> E[패킷4] B --> F[인터넷] C --> F D --> F E --> F F --> G[받는 컴퓨터에서<br/>다시 조립]

    🔨 따라하기¶

    Step 1: 간단한 HTTP 요청 보내기¶

    파이썬으로 웹사이트에 데이터를 요청해보며 프로토콜을 체험해봅시다.

    코드: 

    import requests
import time

print("🌐 HTTP 프로토콜로 데이터 요청하기")
print("-" * 40)

# HTTP GET 요청 보내기
response = requests.get("https://httpbin.org/json")

# 응답 정보 출력
print(f"상태 코드: {response.status_code}")
print(f"응답 시간: {response.elapsed.total_seconds():.2f}초")
print(f"받은 데이터 크기: {len(response.content)}바이트")

    실행 결과: 

    🌐 HTTP 프로토콜로 데이터 요청하기
----------------------------------------
상태 코드: 200
응답 시간: 0.45초
받은 데이터 크기: 429바이트

    Step 2: 패킷 크기 시뮬레이션¶

    큰 데이터가 어떻게 작은 패킷으로 나뉘는지 시뮬레이션해봅시다.

    코드: 

    def simulate_packet_transmission(data, packet_size=10):
    """데이터를 패킷으로 나누어 전송 시뮬레이션"""
    print(f"📦 원본 데이터: '{data}' (길이: {len(data)})")
    print(f"📏 패킷 크기: {packet_size}바이트")
    print("\n🚀 패킷 전송 과정:")

    packets = []
    for i in range(0, len(data), packet_size):
        packet = data[i:i+packet_size]
        packet_num = len(packets) + 1
        packets.append(f"패킷{packet_num}: {packet}")
        print(f"  전송 중... 패킷{packet_num}: '{packet}'")
        time.sleep(0.5)  # 전송 시간 시뮬레이션

    print(f"\n✅ 총 {len(packets)}개 패킷으로 전송 완료!")
    return packets

# 시뮬레이션 실행
message = "안녕하세요! 네트워크 프로토콜을 배우고 있어요."
packets = simulate_packet_transmission(message, 8)

    Step 3: 패킷 재조립¶

    받은 패킷들을 다시 원본 데이터로 조립해봅시다.

    코드: 

    def reassemble_packets(packets):
    """패킷들을 다시 조립"""
    print("\n🔧 패킷 재조립 중...")

    # 패킷에서 실제 데이터 부분만 추출
    data_parts = []
    for packet in packets:
        data_part = packet.split(": ")[1]  # "패킷1: 데이터" -> "데이터"
        data_parts.append(data_part)
        print(f"  조립 중... {packet}")

    # 모든 데이터 합치기
    reassembled = "".join(data_parts)
    print(f"\n🎉 재조립 완료: '{reassembled}'")
    return reassembled

# 재조립 실행
original_message = reassemble_packets(packets)

    📝 전체 코드¶

    import requests
import time

def demonstrate_protocol():
    """프로토콜 기본 개념 시연"""
    print("🌐 HTTP 프로토콜로 데이터 요청하기")
    print("-" * 40)

    response = requests.get("https://httpbin.org/json")
    print(f"상태 코드: {response.status_code}")
    print(f"응답 시간: {response.elapsed.total_seconds():.2f}초")
    print(f"받은 데이터 크기: {len(response.content)}바이트")

def simulate_packet_transmission(data, packet_size=8):
    """패킷 전송 시뮬레이션"""
    print(f"\n📦 원본 데이터: '{data}' (길이: {len(data)})")
    print(f"📏 패킷 크기: {packet_size}바이트")
    print("\n🚀 패킷 전송 과정:")

    packets = []
    for i in range(0, len(data), packet_size):
        packet = data[i:i+packet_size]
        packet_num = len(packets) + 1
        packets.append(f"패킷{packet_num}: {packet}")
        print(f"  전송 중... 패킷{packet_num}: '{packet}'")
        time.sleep(0.3)

    print(f"\n✅ 총 {len(packets)}개 패킷으로 전송 완료!")
    return packets

def reassemble_packets(packets):
    """패킷 재조립"""
    print("\n🔧 패킷 재조립 중...")
    data_parts = []
    for packet in packets:
        data_part = packet.split(": ")[1]
        data_parts.append(data_part)
        print(f"  조립 중... {packet}")

    reassembled = "".join(data_parts)
    print(f"\n🎉 재조립 완료: '{reassembled}'")
    return reassembled

# 실행
if __name__ == "__main__":
    demonstrate_protocol()

    message = "안녕하세요! 네트워크를 배워요."
    packets = simulate_packet_transmission(message)
    reassemble_packets(packets)

    ⚠️ 주의할 점¶

    1. 패킷 순서가 바뀔 수 있어요 실제 인터넷에서는 패킷들이 서로 다른 경로로 전송되어 순서가 바뀔 수 있습니다. TCP가 이를 다시 정렬해줍니다.

    2. 프로토콜이 다르면 통신 불가 HTTP와 FTP는 서로 다른 프로토콜이므로 직접 통신할 수 없습니다.

    ✅ 점검하기¶

    1. 프로토콜이 없다면 컴퓨터 통신에서 어떤 문제가 발생할까요?
    정답 확인 서로 다른 방식으로 데이터를 해석하여 통신이 불가능해집니다. 마치 서로 다른 언어를 쓰는 사람들이 대화할 수 없는 것과 같아요.
    1. TCP/IP 4계층 중 IP 주소를 다루는 계층은?
    정답 확인 인터넷 계층(Internet Layer)입니다. 이 계층에서 목적지 주소를 찾아 데이터를 라우팅합니다.
    1. 큰 파일을 패킷으로 나누어 보내는 이유는?
    정답 확인 네트워크 효율성을 높이고, 오류 발생 시 전체가 아닌 해당 패킷만 재전송하면 되며, 여러 경로로 동시 전송이 가능하기 때문입니다.
