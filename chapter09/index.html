Chapter 09. 생각해보기 — 냉장고가 장을 본다고?¶

🎯 이 장에서 배우는 것¶

  • 사물인터넷(IoT)의 정의를 정확히 설명할 수 있다
  • 일상에서 접할 수 있는 IoT 기기 사례를 5가지 이상 나열할 수 있다
  • IoT가 등장하게 된 배경을 설명할 수 있다

💭 생각해보기: 상상이 현실이 되다¶

아침에 일어나니 냉장고에서 알림이 왔어요. "우유가 떨어져 가네요. 자동으로 주문할까요?" 😲

이게 정말 가능한 일일까요? 냉장고가 어떻게 우유가 떨어져 간다는 걸 알 수 있을까요?

답은 바로 '사물인터넷(IoT)' 때문입니다!

📚 핵심 개념¶

개념: 사물인터넷(IoT)¶

비유로 이해하기: IoT는 마치 모든 사물에 '눈과 입'을 달아주는 것과 같아요. 눈(센서)으로 주변을 보고, 입(통신)으로 다른 사물들과 대화할 수 있게 하는 거죠.

정확한 정의: - IoT(Internet of Things): 사물에 센서와 통신 기능을 내장하여 인터넷으로 연결하는 기술 - 사물들이 스스로 정보를 수집하고, 다른 사물이나 사람과 소통할 수 있게 만드는 기술

IoT의 핵심 요소 3가지:

graph LR A[센서 📡] --> B[네트워크 🌐] B --> C[데이터 처리 💻] C --> D[스마트한 동작 🤖] D --> A
  1. 센서: 온도, 습도, 움직임 등을 감지
  2. 네트워크: 인터넷으로 다른 기기들과 연결
  3. 데이터 처리: 수집한 정보를 분석하여 의미 있는 행동 결정

🏠 우리 집 속 IoT 기기들¶

이미 우리 곁에 있는 IoT 친구들¶

스마트폰 📱 - 위치, 걸음 수, 심박수 측정 - 다른 스마트 기기들을 제어하는 리모컨 역할

AI 스피커 🔊 - 음성 명령을 인식 - 날씨, 음악, 스마트홈 제어

스마트워치 ⌚ - 심박수, 수면 패턴 모니터링 - 운동량 자동 측정

로봇청소기 🤖 - 집 구조를 학습하여 효율적으로 청소 - 스마트폰으로 원격 제어 가능

스마트 TV 📺 - 인터넷 연결로 다양한 콘텐츠 시청 - 음성 명령으로 채널 변경

🔨 따라하기: IoT 냉장고 시뮬레이션¶

실제 IoT 냉장고가 어떻게 작동하는지 파이썬으로 간단히 시뮬레이션해보겠습니다.

Step 1: 냉장고 센서 만들기¶

class SmartFridge:
    def __init__(self):
        self.items = {"우유": 2, "계란": 5, "사과": 3}
        print("🏠 스마트 냉장고가 켜졌습니다!")

    def check_items(self):
        print("\n📊 현재 냉장고 상태:")
        for item, count in self.items.items():
            print(f"   {item}: {count}개")
        return self.items

# 냉장고 생성
my_fridge = SmartFridge()
my_fridge.check_items()

Step 2: 자동 주문 기능 추가¶

def auto_order(self):
    print("\n🤖 자동 주문 시스템 작동중...")
    need_order = []

    for item, count in self.items.items():
        if count <= 1:  # 1개 이하면 주문 필요
            need_order.append(item)
            print(f"⚠️  {item}가 부족합니다! (남은 개수: {count})")

    if need_order:
        print(f"📦 다음 상품을 자동 주문합니다: {', '.join(need_order)}")
    else:
        print("✅ 모든 상품이 충분합니다!")

# SmartFridge 클래스에 메소드 추가
SmartFridge.auto_order = auto_order

# 우유를 사용해보기
my_fridge.items["우유"] = 1  # 우유 1개만 남음
my_fridge.auto_order()

Step 3: 스마트폰 알림 기능¶

def send_notification(self, message):
    print(f"📱 스마트폰 알림: {message}")

def daily_check(self):
    print("\n🌅 매일 아침 자동 점검 중...")
    self.check_items()
    self.auto_order()
    self.send_notification("냉장고 상태를 확인했어요!")

# 메소드 추가
SmartFridge.send_notification = send_notification  
SmartFridge.daily_check = daily_check

# 매일 점검 실행
my_fridge.daily_check()

    def __init__(self):

        print("🏠 스마트 냉장고가 켜졌습니다!")

        print("\n📊 현재 냉장고 상태:")

            print(f"   {item}: {count}개")
        return self.items

    def auto_order(self):
        print("\n🤖 자동 주문 시스템 작동중...")
        need_order = []

        for item, count in self.items.items():
            if count <= 1:
                need_order.append(item)

🌍 IoT가 등장한 이유¶

기술 발전의 3대 요소¶

graph TD A[센서 기술 발전 📡] --> D[IoT 등장 🚀] B[인터넷 확산 🌐] --> D C[스마트폰 보급 📱] --> D A --> A1[작고 저렴해짐] B --> B1[언제 어디서나 연결] C --> C1[모든 사람이 사용]

1990년대: 센서는 크고 비쌌어요 2000년대: 인터넷이 집집마다 연결되기 시작 2010년대: 스마트폰으로 모든 걸 제어할 수 있게 됨 2020년대: AI까지 더해져서 더욱 똑똑해짐

⚠️ 주의할 점¶

1. 개인정보 보호: IoT 기기들이 수집하는 데이터가 안전하게 관리되고 있는지 확인해야 해요.

2. 보안 위험: 해커들이 IoT 기기를 통해 집 안으로 침입할 수도 있으니 보안 설정을 꼼꼼히 해야 합니다.

✅ 점검하기¶

  1. IoT의 정의를 한 문장으로 설명해보세요.
정답 확인 사물에 센서와 통신 기능을 내장하여 인터넷으로 연결하는 기술입니다.
  1. 우리 집에서 찾을 수 있는 IoT 기기 3가지를 말해보세요.
정답 확인 스마트폰, AI 스피커, 스마트 TV, 로봇청소기, 스마트워치 등 (이 중 아무거나 3가지)
  1. IoT 냉장고가 자동으로 우유를 주문하려면 어떤 기능들이 필요할까요?
정답 확인 센서(식재료 인식), 네트워크(인터넷 연결), 데이터 처리(부족 여부 판단), 자동 주문 시스템이 필요합니다.
