    IoT의 구조 — 센서 → 네트워크 → 서비스¶

    🎯 이 장에서 배우는 것¶

    • IoT 시스템의 3계층 구조(센서-네트워크-서비스)를 설명할 수 있다
    • 센서와 액추에이터의 차이점을 구분할 수 있다
    • 실생활 IoT 사례를 3계층으로 분석할 수 있다

    📚 핵심 개념¶

    개념: IoT의 3계층 구조¶

    비유로 시작: "IoT는 마치 우리 몸의 신경계와 같아요. 눈(센서)으로 본 것이 신경(네트워크)을 통해 뇌(서비스)로 전달되고, 뇌가 판단해서 손(액추에이터)으로 행동하는 것처럼 말이에요!"

    정확한 정의: IoT 시스템은 다음 3개 계층으로 구성됩니다:

    1. 디바이스 계층 🎯
    2. 센서: 환경 정보를 수집 (온도, 습도, 움직임 등)

    3. 액추에이터: 물리적 동작을 수행 (모터, LED, 스피커 등)

    4. 네트워크 계층 🌐

    5. 데이터 전송 통로 (WiFi, 블루투스, 4G/5G 등)

    6. 디바이스와 서비스를 연결하는 다리 역할

    7. 서비스 계층 ☁️

    8. 데이터 분석 및 의사결정
    9. 사용자 인터페이스 제공 (앱, 웹사이트)
    flowchart LR A[센서<br/>🌡️온도측정] --> B[네트워크<br/>📶WiFi] B --> C[서비스<br/>☁️클라우드] C --> D[네트워크<br/>📶WiFi] D --> E[액추에이터<br/>❄️에어컨] style A fill:#e1f5fe style E fill:#fff3e0 style C fill:#f3e5f5

    예시로 확인: 스마트홈 시나리오 - 온도 센서가 28도 측정 → WiFi로 클라우드 전송 → 서비스에서 "너무 덥다" 판단 → 에어컨 가동 명령 전송 → 에어컨 동작

    🔨 따라하기¶

    Step 1: 센서와 액추에이터 구분하기¶

    활동: 우리 교실의 IoT 장치들을 찾아보세요!

    센서 (입력 장치): 

    🎤 마이크 - 소리 감지
📷 카메라 - 영상 촬영  
🌡️ 온도계 - 온도 측정
💡 조도센서 - 밝기 측정

    액추에이터 (출력 장치): 

    🔊 스피커 - 소리 출력
💡 전등 - 빛 출력
❄️ 에어컨 - 온도 조절
📱 디스플레이 - 화면 출력

    Step 2: 실제 IoT 제품 분석하기¶

    선택한 제품: 스마트 도어락

    graph TD A[지문센서 👆] --> B[WiFi 📶] C[카메라 📷] --> B D[터치패드 🔢] --> B B --> E[스마트폰 앱 📱] E --> F[클라우드 서비스 ☁️] F --> G[WiFi 📶] G --> H[도어락 모터 🔓] G --> I[알림 LED 💡] style A fill:#e1f5fe style C fill:#e1f5fe style D fill:#e1f5fe style H fill:#fff3e0 style I fill:#fff3e0 style F fill:#f3e5f5

    Step 3: 데이터 흐름 이해하기¶

    정보의 여행 경로: 1. 센서 데이터 수집 📊 2. 네트워크로 전송 🚀
    3. 클라우드에서 분석 🧠 4. 결정사항을 다시 전송 📡 5. 액추에이터가 동작 🎬

    📝 전체 시스템 예시¶

    ⚠️ 주의할 점¶

    1. 센서 ≠ 액추에이터: 센서는 정보를 "감지"하고, 액추에이터는 "동작"을 수행합니다.

    2. 네트워크 중요성: 네트워크가 끊어지면 IoT 시스템 전체가 작동하지 않습니다. 마치 전화선이 끊어지면 통화를 할 수 없는 것과 같아요!

    ✅ 점검하기¶

    1. 스마트 워치에서 센서와 액추에이터를 각각 2개씩 찾아보세요.
    정답 확인 센서: 심박센서, 가속도센서, GPS센서 등 액추에이터: 진동모터, 디스플레이, 스피커 등
    1. IoT 시스템에서 네트워크 계층의 역할은 무엇인가요?
    정답 확인 센서에서 수집한 데이터를 서비스로 전달하고, 서비스의 명령을 액추에이터로 전송하는 연결 통로 역할
    1. 만약 집의 WiFi가 끊어진다면 스마트홈 기기들은 어떻게 될까요?
    정답 확인 네트워크 연결이 끊어져서 원격 제어가 불가능하고, 자동화 기능도 작동하지 않습니다. 단, 기기 자체의 기본 기능은 사용 가능할 수 있습니다.
