Chapter 12: AI실을 IoT로 재설계하기 — 상상을 현실로¶

🎯 이 장에서 배우는 것¶

  • AI실 환경에 적용할 수 있는 IoT 시나리오를 기획할 수 있다
  • 센서·네트워크·서비스 요소를 포함한 간단한 IoT 설계도를 작성할 수 있다
  • 기획한 IoT 시나리오를 발표하고 피드백을 주고받을 수 있다

📚 핵심 개념¶

개념 1: IoT 시스템 설계 프로세스¶

비유로 시작: IoT 시스템을 설계하는 것은 마치 건축가가 집을 설계하는 것과 같아요. 먼저 어떤 기능이 필요한지 계획하고, 어떤 재료와 도구를 사용할지 결정한 후, 전체적인 구조를 그려보는 과정입니다.

정확한 정의: IoT 시스템 설계 프로세스는 문제 정의 → 센서 선택 → 네트워크 설계 → 서비스 기능 설계 → 통합 테스트의 5단계로 진행되는 체계적인 접근 방법입니다.

예시로 확인:

graph TD A[문제 정의: AI실이 너무 더워요] --> B[센서 선택: 온습도 센서] B --> C[네트워크: Wi-Fi로 데이터 전송] C --> D[서비스: 에어컨 자동 제어] D --> E[통합: 스마트 온도 관리 시스템]

개념 2: IoT 워크시트 작성법¶

비유로 시작: IoT 워크시트는 마치 요리 레시피와 같아요. 어떤 재료(센서)가 필요한지, 어떤 순서로 조리(처리)할지, 최종적으로 어떤 요리(서비스)를 만들지 단계별로 정리하는 것입니다.

정확한 정의: IoT 워크시트는 센서 정보, 네트워크 경로, 서비스 기능, 예상 효과를 체계적으로 정리한 설계 문서입니다.

워크시트 구성 요소: - 센서부: 어떤 데이터를 수집할지 - 네트워크부: 데이터를 어떻게 전송할지
- 서비스부: 수집된 데이터로 무엇을 할지 - 효과부: 기대되는 결과와 개선점

🔨 따라하기¶

Step 1: 문제 상황 정의하기¶

우리 AI실의 불편한 점을 찾아보세요.

예시 문제들: - 교실이 너무 어둡거나 밝아서 화면이 잘 안 보여요 - 공기가 답답해서 집중하기 어려워요 - 소음 때문에 수업에 방해받아요 - 의자나 책상 높이가 맞지 않아요

Step 2: IoT 솔루션 기획하기¶

선택한 문제를 해결할 IoT 시스템을 설계해보세요.

예시 - 스마트 조명 시스템: 

# IoT 시나리오 예시 코드
class SmartLightingSystem:
    def __init__(self):
        self.light_sensor = 0  # 조도 센서 값
        self.screen_brightness = 50  # 전자칠판 밝기

    def read_light_level(self):
        # 조도 센서에서 밝기 값 읽기
        self.light_sensor = 300  # 예시 값 (lux)
        return self.light_sensor

    def adjust_screen_brightness(self):
        # 조도에 따라 화면 밝기 자동 조절
        if self.light_sensor < 200:
            self.screen_brightness = 80  # 어두우면 밝게
        elif self.light_sensor > 500:
            self.screen_brightness = 30  # 밝으면 어둡게
        else:
            self.screen_brightness = 50  # 적당하면 보통

        return f"화면 밝기를 {self.screen_brightness}%로 조절했습니다"

# 시스템 테스트
smart_light = SmartLightingSystem()
current_light = smart_light.read_light_level()
result = smart_light.adjust_screen_brightness()
print(f"현재 조도: {current_light} lux")
print(result)

실행 결과: 

현재 조도: 300 lux
화면 밝기를 50%로 조절했습니다

Step 4: 모둠 발표 및 피드백¶

각 모둠이 설계한 IoT 시스템을 3분간 발표하고, 다른 모둠의 피드백을 받아보세요.

발표 체크리스트: - 문제 상황을 명확히 설명했나요? - 센서 선택 이유가 적절한가요? - 서비스 기능이 문제 해결에 도움이 되나요? - 실제 구현 가능성이 있나요?

📝 전체 코드¶

class AIClassroomIoTDesigner:
    def __init__(self, problem_description):
        self.problem = problem_description
        self.sensors = []
        self.network = ""
        self.services = []
        self.expected_effects = []

    def add_sensor(self, sensor_type, measurement, location):
        sensor = {
            'type': sensor_type,
            'measurement': measurement,
            'location': location
        }
        self.sensors.append(sensor)
        print(f"센서 추가됨: {sensor_type} - {location}에 설치")

    def set_network(self, connection_type, frequency):
        self.network = f"{connection_type} ({frequency})"
        print(f"네트워크 설정: {self.network}")

    def add_service(self, service_name, description):
        service = {
            'name': service_name,
            'description': description
        }
        self.services.append(service)
        print(f"서비스 추가됨: {service_name}")

    def add_expected_effect(self, effect):
        self.expected_effects.append(effect)

    def generate_report(self):
        print("\n" + "="*50)
        print("AI실 IoT 설계 보고서")
        print("="*50)
        print(f"해결 문제: {self.problem}")
        print(f"\n센서 구성: {len(self.sensors)}개")
        for sensor in self.sensors:
            print(f"  - {sensor['type']}: {sensor['measurement']} ({sensor['location']})")
        print(f"\n네트워크: {self.network}")
        print(f"\n서비스 기능: {len(self.services)}개")
        for service in self.services:
            print(f"  - {service['name']}: {service['description']}")
        print(f"\n기대 효과:")
        for effect in self.expected_effects:
            print(f"  - {effect}")

# 사용 예시
designer = AIClassroomIoTDesigner("교실 온도가 불균일해서 학습 집중도가 떨어짐")
designer.add_sensor("온습도 센서", "온도/습도", "교실 4곳")
designer.add_sensor("인체감지 센서", "재실 인원", "출입문")
designer.set_network("Wi-Fi", "1분마다")
designer.add_service("스마트 에어컨", "인원수와 온도에 따른 자동 제어")
designer.add_service("환경 모니터링", "실시간 온습도 대시보드")
designer.add_expected_effect("쾌적한 학습 환경 조성")
designer.add_expected_effect("에너지 효율성 20% 향상")
designer.generate_report()

⚠️ 주의할 점¶

현실성 고려하기: 아무리 좋은 아이디어라도 예산과 기술적 제약을 고려해야 합니다. 센서 가격, 설치 난이도, 유지보수 비용을 함께 생각해보세요.

개인정보 보호: 카메라나 음성 인식 센서를 사용할 때는 개인정보 보호 문제를 반드시 고려해야 합니다. 데이터 수집 범위와 활용 목적을 명확히 정의하세요.
