    2. IP 주소 이해하기¶

    학교 컴퓨터의 IP 주소가 192.168.1.100일 때, 같은 네트워크에 있을 가능성이 높은 IP 주소는? ① 10.0.0.100 ② 192.168.2.100 ③ 192.168.1.50 ④ 172.16.1.100

    4. IoT 시스템 구조¶

    IoT 시스템에서 센서 → ( ) → 클라우드 순서로 데이터가 전송됩니다. ( )에 들어갈 것은? ① 액추에이터 ② 게이트웨이 ③ 데이터베이스 ④ 사용자

    5. 네트워크 토폴로지¶

    모든 장치가 중앙 장치에 연결된 네트워크 구조는? ① 버스형 ② 링형 ③ 스타형 ④ 메시형

    웹 브라우저가 동작하는 OSI 계층은? ① 물리 계층 ② 데이터링크 계층 ③ 네트워크 계층 ④ 응용 계층

    7. 클라우드 컴퓨팅¶

    8. AI와 컴퓨팅 시스템¶

    AI가 컴퓨팅 시스템에 미치는 영향으로 올바른 것은? ① 연산 능력 요구 감소 ② 자동화와 지능화 촉진 ③ 네트워크 불필요 ④ 하드웨어 단순화

    9. 보안의 3요소¶

    정보 보안의 3요소에 포함되지 않는 것은? ① 기밀성 ② 무결성 ③ 가용성 ④ 편의성

    10. 데이터 처리 과정¶

    빅데이터 처리 과정을 올바른 순서로 나열한 것은? ① 수집→저장→분석→활용 ② 분석→수집→저장→활용 ③ 저장→수집→분석→활용 ④ 활용→분석→수집→저장
